Redis注册

1.运行windows cmd命令，进入Redis安装目录D:\redis_3.2.100\Redis-x64-3.2.100

2.执行注册服务命令 redis-server –service-install redis.windows-service.conf

3.如果需要卸载Redis服务，执行redis-server –service-uninstall
