Redis 注册

1. 运行 windows cmd 命令，进入 Redis 安装目录 D:\redis_3.2.100\Redis-x64-3.2.100

2. 执行注册服务命令 redis-server –service-install redis.windows-service.conf

3. 如果需要卸载 Redis 服务，执行 redis-server –service-uninstall
