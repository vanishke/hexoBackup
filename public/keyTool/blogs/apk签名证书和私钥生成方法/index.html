apk 签名证书和私钥生成方法

发表于 2025-11-14 更新于 2026-08-14 分类于 keyTool 本文字数： 643 阅读时长 ≈ 2 分钟
  • 使用 keytool 生成密钥对，存储到 JKS 格式的密钥库中
  • 从 JKS 密钥库中导出证书（DER 格式，包含公钥
  • 使用 openssl 将 DER 格式证书转换为 PEM 格式（文本格式，便于查看和使用
  • 将 JKS 格式密钥库转换为 PKCS12 格式 (更通用的密钥库格式，跨平台支持更好)
  • 从 PKCS12 密钥库中提取私钥 (PEM 格式，文本)
  • 将 PEM 格式私钥转换为 PKCS#8 DER 格式 (二进制，常用于 Java 等平台)

使用 keytool 生成密钥对，存储到 JKS 格式的密钥库中

keytool -genkeypair \
  -alias istore \                  
  -keyalg RSA \                    
  -keysize 2048 \                  
  -validity 3650 \                 
  -keystore istore.jks \           
  -storepass 123456 \              
  -keypass 123456

参数

-alias 密钥对的别名（用于标识该密钥对，后续操作需引用）

-keyalg 加密算法为 RSA（非对称加密算法）

-keysize 密钥长度 2048 位（安全性较高，常用长度）

-validity 证书有效期 10 年（3650 天）

-keystore 生成的密钥库文件名为 istore.jks（JKS 是 Java 默认格式）

-storepass 密钥库的访问密码（保护整个密钥库）

-keypass 密钥对自身的密码（保护私钥，此处与密钥库密码相同）

从 JKS 密钥库中导出证书（DER 格式，包含公钥

keytool -exportcert \
  -alias istore \                  
  -keystore istore.jks \           
  -storepass 123456 \              
  -file istore.cer

参数

-alias 要导出的密钥对别名（需与生成时一致）

-keystore 源密钥库文件

-storepass 密钥库访问密码（验证权限）

-file 导出的证书文件名（DER 格式，二进制）

使用 openssl 将 DER 格式证书转换为 PEM 格式（文本格式，便于查看和使用

openssl x509 \
  -inform der \                    
  -in istore.cer \                 
  -out public.pem

参数

-inform 输入格式为 DER（二进制）

-in 输入的 DER 格式证书文件

-out 输出的 PEM 格式文件（包含公钥）

将 JKS 格式密钥库转换为 PKCS12 格式 (更通用的密钥库格式，跨平台支持更好)

keytool -importkeystore \
  -srckeystore istore.jks \        
  -srcstoretype JKS \              
  -srcstorepass 123456 \           
  -destkeystore istore.p12 \       
  -deststoretype PKCS12 \          
  -deststorepass 123456 \          
  -alias istore

参数

-srckeystore 源 JKS 密钥库

-srcstoretype 源密钥库类型为 JKS

-srcstorepass 源密钥库密码

-destkeystore 目标 PKCS12 密钥库文件名

-deststoretype 目标密钥库类型为 PKCS12

-deststorepass 目标密钥库密码

-alias 要转换的密钥对别名

从 PKCS12 密钥库中提取私钥 (PEM 格式，文本)

openssl pkcs12 \
  -in istore.p12 \                 
  -nodes \                         
  -nocerts \                       
  -out temp_private_key.pem

参数

-in 输入的 PKCS12 密钥库

-nodes 不加密私钥（否则会要求设置私钥密码）

-nocerts 只提取私钥，不提取证书

-out 输出的临时私钥文件（PEM 格式）

将 PEM 格式私钥转换为 PKCS#8 DER 格式 (二进制，常用于 Java 等平台)

openssl pkcs8 \
  -topk8 \                         
  -inform PEM \                    
  -outform DER \                   
  -in temp_private_key.pem \       
  -out private.pk8 \               
  -nocrypt

参数

-topk8 转换为 PKCS#8 格式（私钥的标准格式）

-inform 输入格式为 PEM（文本）

-outform 输出格式为 DER（二进制）

-in 输入的 PEM 格式私钥

-out 输出的 PKCS#8 DER 格式私钥文件

-nocrypt 不加密输出文件（否则会要求设置密码）
