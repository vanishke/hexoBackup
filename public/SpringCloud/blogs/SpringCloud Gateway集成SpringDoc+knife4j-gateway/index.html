环境

Java: 1.8
SpringBoot: 2.6.6
SpringCloud: 2021.0.6
springDoc: 1.6.9
knife-gateway:4.4.0

升级原因

原本项目 api 文档由 knife+Swagger2.0 实现，springBoot 升级 2.6.6，发现 swagger2.0 已经停止 维护，knife 后续版本也只兼容适配 swagger3.0, 也就是 openapi, 并且 Swagger2.0 最高只能集成 knife-2.0.9
, 由于考虑到 knife 的兼容性，于是将 swagger2.0 升级为 openapi,knife 升级为 knife-gateway.
