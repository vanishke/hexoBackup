Tcpdump 抓包

发表于 2023-07-28 更新于 2026-10-26 分类于 Linux 本文字数： 541 阅读时长 ≈ 2 分钟

概述

在 Linux 上排查接口异常或怀疑特定客户端请求异常时，需要按 源 IP、目的 IP、端口 抓取报文并离线分析。本文用 tcpdump 按条件抓包、落盘，再用 Wireshark 按字符串检索关键字段。

项说明
目标抓取指定源 / 目的主机与端口的流量
工具tcpdump + Wireshark
产出.cap 文件，可用 -r 回放或图形界面打开

环境示例：

角色示例地址
抓包主机网卡eth1
源主机10.20.35.88
目的主机10.20.35.31
目的端口8080
落盘文件/tmp/app-8080.cap

常用选项

选项含义
-i指定网卡
-w写入文件，不在终端解析打印
-r从文件读取报文
-n不把 IP 反解成域名
-t输出不显示时间戳
-v / -vv增加输出详细程度
-c抓取指定包数量后退出
-s每包捕获长度；0 表示完整报文
-A以 ASCII 打印载荷
-e打印数据链路层头
-q简洁输出
-Q选择入向 / 出向报文

核心步骤

按源、目的与端口抓包

在业务主机上执行（需有抓包权限，通常为 root）：

参数含义
port 8080匹配该端口
src host / dst host限定源、目的地址
-s 0抓完整报文，避免载荷被截断
-w写入 /tmp/app-8080.cap

结束抓包：终端里 Ctrl+C。确认文件：

用 Wireshark 按关键字检索

  1. 用 Wireshark 打开 /tmp/app-8080.cap
  2. 打开查找（搜索图标）
  3. 搜索类型改为 字符串
  4. 输入关键字后查找

常见问题

问题原因处理
抓不到包网卡名不对或流量不经该口ip -br a 核对接口；确认访问路径
文件很大但分析无载荷-s 过小截断使用 -s 0 重抓
Permission denied非特权用户sudo 或赋予 CAP_NET_RAW

按上述过滤条件抓包并落盘后，即可在 Wireshark 中定位请求关键字与异常报文。
