环境

Linux : CentOS Linux release 7.6.1810 (Core)
MySQL : 5.7

背景

现网模块在运行一段时间之后发现产生大量业务日志，占用系统硬盘空间，需要在线将历史数据清除，只保留1年的记录

实现

按日期统计查询t_sys_log表数据

创建一张和原始表一样结构的新表

将2023年的业务日志记录暂存到t_sys_log_new

清空原始表
删除原始表

将新表重命名为原始表
