ElasticSearch-8.8.0 实现分词插件支持

环境

Linux：CentOS Linux release 7.9.2009 (Core)
ElasticSearch： 8.8.0

插件安装

Elasticsearch 为了索引支持中文拼音分词，简繁转换，需要安装 analysis-ik、analysis-pinyin、analysis-stconvert 插件，上述插件都没有 8.8.0 版本，下载 8.8.1 版本，通过修改插件版本配置描述文件更改版本校验，使得 ElasticSearch 启动能够兼容，并正常使用。
插件下载地址：https://release.infinilabs.com/
插件下载完成之后解压上传到 Elasticsearch plugins 目录下，并修改插件对应文件夹为 ik、pinyin、stconvert，如下图所示：
