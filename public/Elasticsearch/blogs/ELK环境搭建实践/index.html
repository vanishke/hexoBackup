ELK 环境搭建实践

发表于 2021-11-09 更新于 2026-08-10 分类于 Elasticsearch 本文字数： 3.9k 阅读时长 ≈ 14 分钟

工具安装包下载

elasticsearch 官方地址
百度云地址 提取码：op7h

Elasticsearch、logstash、kibana 三者使用同一版本 7.15.1

Elasticsearch

上传安装包到指定的目录 /usr/local/ELK/

解压 elasticsearch 安装包，cd 命令进入解压目录 /usr/local/ELK/elasticsearch-7.15.1

ElasticSearch 配置文件实例

安装 head 插件

head 插件地址：git://github.com/mobz/elasticsearch-head.git
下载之后将插件上传到 Elasticsearch 目录，创建一个自定义目录（放在原有 plugins 目录启动会报错）
global_plugins 为自行创建目录，plugins 为原有目录

head 插件启动需要 nodeJs 环境，没有的情况下安装一下

ElasticSearch 不能以 Root 用户启动，创建指定 ElasticSearch 用户

更改 es 用户默认文件数配置

修改完上述文件重启服务器才能生效，使用 ulimit -a 命令查看对应用户的参数是否生效

如果上述修改没有生效，可能 /etc/profile 内部有做特殊指定, 修改对应配置后执行 source /etc/profile 命令后生效 (只能在当前窗口生效，之前打开的窗口没有作用)

提供临时设置的命令 (当前窗口生效)

修改 ElasticSearch 启动 jdk 配置，7.15.1 版本默认自带 jDK，修改启动脚本，指定 JDK 路径 ES_JAVA_HOME (必须为 ES_JAVA_HOME,JAVA_HOME Elasticsearch 不识别)
cd /usr/local/ELK/elasticsearch-7.15.1/bin

启动 elsaticsearch

访问验证

Head 插件配置，修改 Elasticsearch 地址
文件所在位置：/usr/local/ELK/elasticsearch-7.15.1/global_plugins/elasticsearch-head/_site/app.js
搜索 localhost:9200，将其改为对应地址即可

Head 插件启动

在 /usr/local/ELK/logstash-7.15.1/config 对应目录下，创建 logstash.conf 配置文件

logstash 启动

-f 参数指定启动配置文件
启动成功后，logstash 监控控制台输出，在控制台随意输入一些信息，logstash 会将信息存入 Elasticsearch, 可以通过 Head 插件查看

kibana 安装

解压对应安装包，进入对应目录

启动 kibana

验证

lib64stdc++ 升级到 gcc4.8
gcc4.8 下载地址

重新启动成功
