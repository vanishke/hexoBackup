Hexo 新建 404

发表于 2022-05-18 更新于 2026-08-14 分类于 Hexo 本文字数： 86 阅读时长 ≈ 1 分钟

新建 404

在站点根目录下, 输入 hexo new page 404, 默认在 Hexo 站点下/source/404/index.md
打开新建的 404 界面，在顶部插入一行，写上 permalink: /404，这表示指定该页固定链接为 http://“主页”/404.html
