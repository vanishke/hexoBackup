参数 badging 标识输出详细信息，执行提示如下错误

问题原因

aapt_linux_64 工具是 32 位，目前系统普遍是 64 位，导致调用 32 位的库函数失败
64 位库函数所在目录 /usr/lib64
32 为库函数所在目录 /usr/lib

解决办法

将 /usr/lib 目录下 libstdc++.so.6 指向 32 为库函数文件
准备一个 32 位 libstdc++.so.6 文件，例如 libstdc++.so.6.0.13
将原始 /usr/lib 目录下 libstdc++.so.6 删除，并创建软连接指向 libstdc++.so.6.0.13

要求

将字段存储的规则信息拆分为多行

实现

借助 mysql.help_topic 辅助表实现

关键点：
b.help_topic_id < (length(a.parentId) - length(REPLACE(a.parentId,’,’,’’))+1)
限制 help_topic 表的连接查询行数与需要拆分字段信息一致
substring_index(substring_index(a.parentId,’,’,b.help_topic_id+1),’,’,-1)
help_topic_id 递增依次取到对应位置截取的数据信息
substring_index 函数
作用：
返回第 count 次出现的分隔符 delim 之前的 expr 的子字符串
参数：
expr：一个 STRING 或 BINARY 表达式。
delim：一个与 expr 类型（指定分隔符）匹配的表达式。
count：用于统计分隔符数量的 INTEGER 表达式。
返回：
结果与类型 expr 匹配。
如果 count 为正，则返回最终的分隔符左侧的所有内容（从左侧开始计算）。
如果 count 为负，则返回最终的分隔符右侧的所有内容（从右侧开始计算）。
