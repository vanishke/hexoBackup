问题分析

  • 当 a,b 都是 string 类型时，比较 a,b 字符序列、长度是否一致，显然’0’ != ‘’
  • 当 a,b 有一个是 number 类型时，先将另外一个转换为 number，空字符串转换为 number = 0，故 0=0 成立
