Tomcat 部署 war, 访问不带项目名称

发表于 2023-10-30 更新于 2026-08-14 分类于 Tomcat 本文字数： 782 阅读时长 ≈ 3 分钟
  • 环境
  • 解决办法

环境

Tomcat: 8.0.38
项目部署 Tomcat 之后，访问后台和接口不带项目名称

解决办法

修改配置文件 server.xml, 文件所在路径：/usr/local/tomcat8/conf/server.xml
添加如下内容：

# path设置为"",docBase设置为对应项目名称，reloadable="true" 标识项目文件的修改不需要重启便可以生效
<Context path="" docBase="myproject" reloadable="true" />

		<Context path="" docBase="myproject" reloadable="true" />

    </Engine>
  </Service>
