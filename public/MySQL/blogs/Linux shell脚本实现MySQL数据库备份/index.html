环境

Linux: CentOS Linux release 7.7.1908 (Core)
MySQL：5.7

背景

线上服务对应数据库没有做备份，担心故障会导致数据丢失和业务异常，所以使用 shell 脚本定时备份数据库。

mysqlBackup.sh

mysqldump 使用绝对路径，否则通过 crontab 系统定时任务支持脚本备份数据为空。
–ignore-table 用于指定备份需要忽略的表项，忽略多个表的情况下指定多次。
BACKUP_SAVE_DAYS 参数控制备份文件只保留 7 天以内。
