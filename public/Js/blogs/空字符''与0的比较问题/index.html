问题分析

  • 当a,b都是string类型时，比较a,b字符序列、长度是否一致，显然’0’ != ‘’
  • 当a,b有一个是number类型时，先将另外一个转换为number，空字符串转换为number = 0，故 0=0成立

解决方案

采用隐式转换，将数字转换成字符再进行比较。
