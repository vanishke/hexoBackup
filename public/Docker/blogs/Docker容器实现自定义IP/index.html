背景

应用使用 docker 容器化后，需要跨宿主机访问，实现要求是宿主机和内部容器可以互通，且外部主机可以直接访问容器服务

工具

bridge-util : linux 系统网桥管理工具
pipework : Docker 网络增强插件

bridge-util 安装

如果没有 yum 环境可以使用离线安装方式，离线安装包地址：
https://www.linuxfromscratch.org/blfs/view/svn/basicnet/bridge-utils.html

pipework 安装

pipework 下载

验证

宿主机访问容器 centos7_1: 10.9.216.101

宿主机访问容器 centos7_2: 10.9.216.102

容器 centos7_1 访问宿主机 10.9.216.14

容器 centos7_1 (10.9.216.101) 访问容器 centos7_2 (10.9.216.102)

容器 centos7_2 访问宿主机 10.9.216.14

容器 centos7_2 (10.9.216.101) 访问容器 centos7_1 (10.9.216.102)

服务器重启之后网桥信息会丢失，需要重新配置
