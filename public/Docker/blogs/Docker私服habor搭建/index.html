环境

Linux: CentOS Linux release 7.7.1908 (Core)
Docker：26.1.4
Docker compose: v2.25.0

背景

docker swarm 模式下实现基于 docker-compose 编排工具的多文件部署，但命令行的操作使得部署变得很麻烦，希望能够通过 portainer+harbor 实现容器的可视化管理。

harbor 部署

官网地址：https://goharbor.io/
github 地址：https://github.com/goharbor/harbor/releases

下载对应的离线版本，上传至 docker 服务器 /usr/local/habor 目录下，执行解压

tar -zxvf harbor-offline-installer-v2.12.1.tgz

解压之后，赋予.sh 脚本文件可执行权限

chmod a+x *.sh

重命名配置文件，并修改配置

mv harbor.yml.tmpl  harbor.yml

主要修改图片中标识三项内容：

hostname: 设置 harbor 服务的域名或者主机 IP

https: 加密安全访问可以通过下面命令生成对应证书文件

#harbor.example.com/10.0.0.10
#指定/home路径下生成certificate.jks证书（口令请自行替换为强口令）
keytool -genkey -alias registry  -keyalg RSA -keysize 2048 -validity 3650 -ext SAN=dns:harbor.example.com,ip:10.0.0.10 -keystore /usr/local/harbor/https/certificate.jks -storepass <STOREPASS> -dname "CN=harbor.example.com, OU=harbor.example.com, O=example, L=your-city, ST=your-state, C=CN"


#certificate.jks是键值对形式的证书，推荐转换为标准格式pkcs12
keytool -importkeystore -srckeystore certificate.jks -destkeystore certificate.jks -deststoretype pkcs12

#将certificate.jks证书导出，certificate.jks已经是pkcs12格式
keytool -export -trustcacerts -alias registry -file /usr/local/harbor/https/cas.crt -keystore /usr/local/harbor/https/certificate.jks -storepass <STOREPASS>

#将cas.crt格式转换为server.pem，方便nginx使用
openssl x509 -inform der -in cas.crt -out server.pem

#提取密钥
openssl pkcs12 -nocerts -nodes -in certificate.jks -out server.key

harbor_admin_password: 默认登录后台管理 admin 用户密码

执行 harbor 服务安装命令:

./install.sh

harbor 服务启动之后其实是由 docker 内部多个服务组成，通过 docker ps 命令可以看到对应的容器服务如下：

harbor 内置 docker-compose 容器编排文件 docker-compose.yml, 服务器重启之后，harbor 对应的容器服务启动失败，原因是容器之间的依赖关系没有设置，导致容器缺失对应的依赖启动失败，容器默认的重启策略 restart: always
解决这一问题的办法是手动执行 docker-compose 命令

#进入habor主目录
cd /usr/local/habor
#docker-compose.yml文件在harbor主目录下指定执行有效，或者不指定的情况下默认使用的也是docker-compose.yml
docker-compose up -d docker-compose.yml

为了解决重启失效的问题，可以将 harbor 注册为系统服务，并在启动时默认执行容器编排服务命令。

创建对应的系统服务

vim  /etc/systemd/system/harbor.service

服务内容添加如下：

[Unit]
Description=Harbor service
Requires=docker.service
After=docker.service
 
[Service]
Type=simple
Restart=always
//改成你的harbor路径
WorkingDirectory=/usr/local/harbor 
//改成你的docker-compost路径 
ExecStart=/usr/local/bin/docker-compose up 
 
[Install]
WantedBy=multi-user.target

设置开机启动和启动

sudo systemctl enable harbor.service
sudo systemctl start harbor.service
