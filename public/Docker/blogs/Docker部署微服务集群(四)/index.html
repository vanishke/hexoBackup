depends_on 导致容器启动异常

depends_on 配置项控制容器的启动顺序，只能保证容器启动顺序，不能实现被依赖容器服务启动完成的情况下再去启动相应的服务，导致加载异常，naocs 依赖 mysql, 但不能保证 MySQL 服务可用的情况下去启动 nacos, 导致启动异常。

容器的依赖改用 docker-compose-wait，实现容器间的心跳检测

Dockerfile 文件加入 docker-compose-wait 支持：

docker-compose-wait 下载地址：https://github.com/ufoscout/docker-compose-wait/releases

docker-compose.yml 编排工具加入对应的环境变量 WAIT_HOSTS、WAIT_TIMEOUT

多个依赖服务的情况下采用逗号分隔

docker-compose.yml 容器编排工具对应的服务没有定义 WAIT_HOSTS 环境变量的情况下，Dockerfile 添加 docker-compsoe-wait 支持不生效
