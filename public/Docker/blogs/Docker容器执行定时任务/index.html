Docker 容器执行定时任务

发表于 2024-12-13 更新于 2026-08-14 分类于 Docker 本文字数： 344 阅读时长 ≈ 1 分钟
  • 环境
  • 背景
  • 容器执行完不退出的方法

环境

Docker: 26.1.4
docker-compose: v2.25.0

背景

docker-compose 编排容器部署后发现 zipkin-dependencies 模块启动之后容器就退出了，因为 zipkin-dependencies 是基于 spark 执行的统计计算任务，导致后续在系统定时任务添加的定时脚本无法执行。

容器执行完不退出的方法

关键点在于 tail -f /var/log/cron.log，表示一直监控定时任务的日志输出。这样可以保证容器执行完计算任务不退出容器，保持在线状态。
