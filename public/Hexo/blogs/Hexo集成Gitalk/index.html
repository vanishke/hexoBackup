发表于 2021-01-15 更新于 2026-08-10 分类于 Hexo 本文字数： 492 阅读时长 ≈ 2 分钟

注册应用

注册地址：https://github.com/settings/applications/new

参数说明：
Application name //应用名称，随便填
Homepage URL //可以填自己的博客地址
Application description //应用描述
Authorization callback URL //填自己要使用 Gitalk 的博客地址

应用注册成功后会生成 Client ID 和 Client Secret，记下这两个参数值，后面配置文件会用到。
