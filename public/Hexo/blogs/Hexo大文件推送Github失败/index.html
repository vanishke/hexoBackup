Hexo大文件推送github失败

发表于2022-05-19|更新于2026-08-10|Hexo
|浏览量:

问题现象

hexo站点根目录目录下执行hexo d命令报错

解决办法

删除对应位置上的文件，发现部署之后仍然报错，该问题需要清空hexo根目录下.deploy_git文件夹，重新部署成功
