Docker部署Minio，分享地址为Docker内ip地址问题

  • 背景
  • 解决办法
  • 验证

背景

通过Docker拉取minio镜像，生成容器访问后发现分享的地址是docker容器内部的ip地址，导致无法访问

解决办法

拉取minio镜像

生成容器并后台启动

-e “MINIO_SERVER_URL=http://192.168.99.100:9000" 参数指定生成minio应用程序分享地址环境变量

验证

再次上传文件并分享后分享图片链接地址
