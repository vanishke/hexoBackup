SpringBoot+Mybatis+Druid 批量更新 multi-statement not allow 异常

发表于 2023-10-26 更新于 2026-08-14 分类于 SpringBoot 本文字数： 442 阅读时长 ≈ 2 分钟
  • 项目环境
  • 问题原因
  • 解决办法
    • 方案一
    • 方案二

项目环境

SpringBoot: 2.2.6.RELEASE
SpringCloud: 2021.0.5
Druid: 1.1.22
Mybatis-plus: 3.3.1

多条 SQL 语句同时执行更新操作，提示报错

问题原因

mysql 默认不支持批量更新
Druid 的 multiStatementAllow 默认是 false

解决办法

方案一

mysql 连接 url 参数添加 allowMultiQueries=true
如果配置了 druid 注释掉 filters: wall，加上
filter:
wall:
config:
multi-statement-allow: true
none-base-statement-allow: true

方案二

DataSourceProperties 配置类添加 SQL 多条更新支持
